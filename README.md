# Methods and Tools

Machine learning lab notebooks. Each topic lives in its own folder, numbered so the
intended order is clear from the name:

```
L01 - Linear Regression with One Variable/

    Solutions/
        L01 - Linear Regression with One Variable_solved.ipynb
```

Shared data files and images live in `assets/`, grouped per lab (`assets/Lab01/`, ...).
The notebooks download the data they need at runtime, so they can be opened directly in
